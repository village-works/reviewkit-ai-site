# ReviewKit SEO System

## Target Guidelines
**Primary Keywords**: 
- AI review
- automatic review
- figma plugin ai review
- accessibility checker

**Brand Name**: ReviewKit

## Meta Tags System

### Title Tag
Format: `[Page Topic] - [Key Value Prop] | ReviewKit` or `ReviewKit - [Main Value Prop]`
- Length: 50-60 characters
- Must include primary keywords near the start if possible.

### Meta Description
- Length: 150-160 characters
- Action-oriented.
- Must include "AI", "Automatic", and "Figma".

### Canonical URL
- Every page must have a `<link rel="canonical" href="...">` tag to prevent duplicate content issues.

### Open Graph (Social)
Required for all pages:
- `og:type`: "website" or "article"
- `og:url`: Full URL
- `og:title`: Same as page title
- `og:description`: Same as meta description
- `og:image`: High-quality preview image (1200x630px recommended)

### Twitter Card
Required for all pages:
- `twitter:card`: "summary_large_image"
- `twitter:title`
- `twitter:description`
- `twitter:image`

## Content Structure

### Headings
- **H1**: Only one per page. Must match the page title's intent.
- **H2-H6**: Use for hierarchy. Do not skip levels.
- **Alt Text**: All meaningful images must have descriptive alt text.

## File Structure & Sitemaps
- `sitemap.xml`: Must include all public pages.
- `robots.txt`: Check for crawlability.
