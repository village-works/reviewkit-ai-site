Four essential accessibility checks

Catch the most common WCAG violations before they make it to production. Each check is based on real accessibility guidelines.

Contrast Ratio

Automatically calculates text-to-background contrast using the WCAG 2.1 luminance formula. Flags any text that doesn't meet AA or AAA standards.

WCAG 1.4.3

Text Size

Ensures all text meets the minimum 12px font size requirement for readability. Small text is one of the most common accessibility issues.

WCAG 1.4.4

Touch Targets

Checks that interactive elements are at least 44x44 pixels. Small touch targets are frustrating for everyone, especially users with motor impairments.

WCAG 2.5.5

Color-Only Indicators

Detects UI elements that may rely solely on color to convey information. Helps ensure your design works for colorblind users.

WCAG 1.4.1
